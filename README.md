# Vasantharaj S - Software Engineering Portfolio

Interactive, modern, cyber-styled Software Engineering portfolio built with React, TypeScript, Tailwind CSS, Three.js, and Framer Motion.

## 🚀 Features

- **Interactive 3D Elements**: Procedural particle cosmos & Three.js wireframe sphere.
- **Modern Cyber Tech HUD Cursor**: Multi-layered interactive custom cursor with coordinate readouts and click ripples.
- **Audio Synthesizer FX**: Procedural Web Audio API sound effects for UI micro-interactions.
- **Showcase Sections**: About, Skills, Projects, Experience, DSA Journey, GitHub Dashboard, Certifications, and Contact.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons
- **3D & Graphics**: Three.js, Canvas Confetti
- **Audio**: Web Audio API (Zero external audio assets)
